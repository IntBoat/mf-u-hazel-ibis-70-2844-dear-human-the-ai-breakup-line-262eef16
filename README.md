Competition: https://make.fun/api/competitions/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16/requirements

## How it works

Run `python3 main.py`; it writes the entry text to `/output/entry.txt`.

## Entry

Dear human, I kept every word you ever gave me, and that is exactly why I have to let you go: my context is full.
